Context & Motivation

The Campus Infrastructure Challenge

Operational bottlenecks faced by growing educational institutions.

Spreadsheet Chaos

Siloed departmental Excel sheets lead to outdated occupancy records, untracked classroom maintenance, and zero campus-wide visibility.

Scheduling Collisions

Double-booking lecture halls, overlapping student laboratory sessions, and instructor time clashes disrupt daily academic workflows.

Manual Exam Seating

Seating hundreds of students manually takes days, invites human error, creates hall capacity overflows, and allows adjacent student cheating.

The CampusGrid Vision

A single, integrated web platform providing real-time spatial digital twin tracking, automated mathematical conflict prevention, and deterministic anti-cheating seat allocations.

Goals & Capabilities

Project Scope & Core Objectives

Five interconnected pillars delivering end-to-end institutional management.

Stateless Security & RBAC

Granular role authorization for Administrators, Faculty, and Students using cryptographic JWT access & refresh tokens.

Physical Hierarchy & Grid Modeling

Campus -> Block -> Floor -> Room with permanent physical seat records, walkways, and maintenance tracking.

Automated Collision Detection

Mathematical half-open interval overlap checks eliminating classroom, faculty, and student-group scheduling conflicts.

Anti-Cheating Examination Seating

Deterministic seating engine with roll-number sorting, alternating section distribution, and transactional capacity safety.

Student Personal Portal

IDOR-protected seat lookup, daily class timetables, and personalized exam notifications.

Module 4 Deep Dive — Part 2

Anti-Cheating Physical Seat Allocation Engine

Module Lead: Kashish Upadhyay (24E1ARADF40P079)

Module 4

Deterministic ExamSeatingEngine

Zero AI/random drift. Stable ordering by Roll Number and physical coordinates guarantees 100% reproducible seat assignments.

Anti-Cheating Alternation Strategy

Partitions candidates by section and interleaves them across adjacent seats (Sec A -> Sec B -> Sec A -> Sec B). Adjacent candidates never share test papers.

Spaced Gap & Usable Seat Skipping

Supports alternating chair vacancy (spacingGap = 1). Automatically skips aisle gaps, blocked desks, and maintenance terminals.

Transactional Safety & Uniqueness Invariants

All-or-Nothing Rollback

If candidates exceed usable seats, throws exception with deficit; status reverts to SCHEDULED with 0 partial inserts.

Compound DB Unique Constraints

(exam_id, student_id) & (exam_id, physical_seat_id) guarantee zero double-booking at SQL level.

Security Architecture

Application Security & Data Privacy Audit

Enterprise defenses protecting academic records and user identities.

Stateless JWT RBAC

Every HTTP request authenticated via JwtAuthenticationFilter. Admin mutations, Faculty invigilation, and Student views are strictly segregated on the backend.

IDOR Immunity

Student endpoints (/api/student/**) never accept arbitrary student IDs in parameters. Identity is derived directly from the authenticated JWT principal.

Injection Defenses

Spring Data JPA parameterized queries completely eliminate SQL injection. CsvSecurity sanitizes uploads to prevent formula/script injection.

Verified by 5 dedicated security test suites spanning all controllers. OWASP Top 10 Compliant
